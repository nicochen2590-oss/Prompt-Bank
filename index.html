B / 启用本机引擎（推荐 · 密钥不进入浏览器）
  1. 不用手动改任何文件：在页面顶部「快速开始」粘一个 API Key，点「保存并连接」即可。推荐 OpenRouter 或 硅基流动，一个 Key 覆盖全部 54 条模型家族。
  2. 双击 启动 Prompt Bank.command（或终端运行 python3 promptbank_engine.py），浏览器会打开 http://127.0.0.1:8765/。
  3. 回到本页，状态灯变绿即已内嵌。此后点任意卡片的「▶ 页面内运行」或 RUN ALL，模型生成结果会直接显示在本页。
为什么不能把网页版对话框直接嵌进 iframe？ ChatGPT / Claude / 通义 / DeepSeek 等网页版都设置了 X-Frame-Options 与 CSP frame-ancestors，浏览器会拒绝第三方页面嵌入；即使绕过，跨域 iframe 也无法自动填入 Prompt 或读取回复。因此「在页面内生成结果」的正规方式是通过模型 API。
本机引擎仅用 Python 标准库实现、只监听 127.0.0.1，负责转发请求并解决跨域；Key 只存在本机配置文件里，页面与浏览器都拿不到。若不想启动脚本，可切到「浏览器直连 API」，但要求端点允许 CORS，且 Key 会存在本机浏览器。
C / 浏览器直连 API（不启动脚本时）
选择「浏览器直连 API」后，请在下方 CONFIG / 配置 面板 A 区填写 API Key；上方服务商预设会自动填好 Base URL 与模型映射。多数国内厂商 API 未开放浏览器跨域，遇到 CORS 报错时请改用本机引擎。
